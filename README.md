# kalliopi

A portmanteau to make a dedicated portable pentesting device.

## Why?

I want a Kali Linux™ that's super portable, and can be controlled using a small onboard screen and d-pad. Specifically, I wanted an alternative to the BlueShark for the proxmark3 Rdv4.

P4wnP1 A.L.O.A focused on HID attacks. Pi-tail relied on tethering to be of any use. pwnagotchi was too automated and only focused on WiFi. pi-pm3 was nearly a perfect solution - all it needed was a d-pad.
